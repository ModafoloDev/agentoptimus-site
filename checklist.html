The agent governance gap checklist

Ten questions to run against your own setup. If you can’t produce the artifact in the middle column, you don’t have the control — you have a habit. The right column lists the answers that feel like proof and aren’t.

Question
What counts as proof
What doesn’t

1 · Permission & blast radius

01For a given agent run, can you enumerate what it was allowed to touch — before it ran?
A per-run allowlist stored with the run record.
“It only had the repo we opened.”
02Can an agent reach a credential it was never granted?
A run where an unauthorized read actually fails.
“Secrets are in .env, so it’s fine.”

2 · Evidence & attestation

03For a merged AI-authored change, can you reproduce the evidence that gated it?
Stored artifacts bound to the commit SHA.
“CI was green.”
04Can you prove that evidence wasn’t altered after the decision?
Content digest, ideally hash-chained.
“It’s in our audit log.”
05Can you attest which model and which vendor served each request?
Recorded model ID plus provider request ID.
“The model is set in config.”

3 · Data egress

06Do you know every network destination a run contacted?
A per-run egress log, default-deny.
“It only talks to the model API.”
07With egress blocked, does the run fail closed — or quietly degrade?
An executed run under deny-by-default.
“We could block it at the firewall.”

4 · Separation of duties

08Is the thing that authors a change ever the thing that approves it?
Distinct enforced identities, not convention.
“A human reviews the PR.”
09Can the agent edit the tests that gate its own work?
A policy that blocks it — with a test proving the block.
“We’d notice in review.”

5 · Cost & runaway

10Is there a ceiling that stops a run, or a dashboard that reports one?
A run observed terminating at the limit.
“We have billing alerts.”

Answered “we’d notice” to more than two?

That’s the gap. It is also the thing that gets expensive the first time somebody outside your team asks you to prove it. Agent Optimus is being built against exactly this list — and it does not yet clear all ten itself. Tell me which line hurt.
