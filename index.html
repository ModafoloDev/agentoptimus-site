The harness, not the model, decides what ships.

Agent Optimus is a desktop-first system for taking work from requirement to shipped software. The model proposes. The harness controls permissions, validation, evidence and release readiness — and records every one of those decisions.

What the harness controls

Isolated task workspaces

Each task gets a scoped workspace. An agent cannot reach repository state it was never granted.

Evidence-gated completion

A task is not done because a model says so. It closes when the required evidence exists and is recorded.

Cost-aware validation

Validation is scheduled against budget policy, with explicit rerun control instead of unbounded spend.

Local-first, no silent egress

Deployment and data-egress surfaces are made visible rather than assumed. Nothing phones home quietly.
